# Source Sans 3

Este dotfiles usa Source Sans 3 como fonte sans-serif da interface. Ela é a
família de interface disponível no [Google Fonts](https://fonts.google.com/specimen/Source+Sans+3)
e também é distribuída pelo pacote Arch `adobe-source-sans-fonts`.

Os arquivos da fonte não são versionados aqui. O comando abaixo instala o
pacote e ativa as regras de fontconfig/GTK deste repositório:

```bash
perl ./omarchy.pl --fonts --backup
```
