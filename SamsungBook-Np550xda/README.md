# Dotfiles — Samsung Book NP550XDA

Personalizações do Samsung NP550XDA-KF2BR para Omarchy e Windows 11: desktop,
fontes, terminais, aplicativos e automação. Os instaladores pressupõem um
sistema operacional instalado; não provisionam partições, bootloader ou drivers.

- [Análise e diagramas das modificações](docs/arquitetura.md): camadas, diferenças
  em relação à base, instalação, energia, serviços e limites de restauração.
- [Perfil Omarchy](Omarchy/README.md): instalação e stack Docker opcional.
- [Perfil Windows 11](Windows-11/README.md): instalação, atalhos e debloat.

Os diagramas são Mermaid, editáveis no próprio Markdown e renderizados pelo
GitHub. A análise documenta o código do repositório; não certifica que todas as
personalizações estejam aplicadas na máquina.
